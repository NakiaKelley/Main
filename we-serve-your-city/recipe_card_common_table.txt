┌──────────────────────────────────────────────────────────────────────────────┐
│ PRODUCTION STEPS                                                             │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ PREP (Complete 1 day prior to assembly):                                    │
│   1. Cook brown rice: Rinse, cook in 1:2 ratio (rice:water), cool          │
│      completely on sheet pans in walk-in refrigerator.                      │
│   2. Cook quinoa: Rinse, cook in 1:1.5 ratio, fluff, cool completely.      │
│   3. Roast chicken: Season with herbs, roast at 375°F to 165°F internal,   │
│      cool, dice into ½-inch cubes, refrigerate.                             │
│   4. Roast Brussels sprouts: Halve, toss with olive oil & salt, roast at   │
│      400°F for 20-25 min until caramelized, cool completely.                │
│   5. Wash & dry all greens thoroughly using salad spinner.                  │
│   6. Slice red onion thinly, soak in ice water 10 min, drain & dry.        │
│   7. Dice apples, toss with lemon juice to prevent browning.               │
│                                                                              │
│ ASSEMBLY (Cold assembly on day of production):                              │
│   8. Verify all components are at proper temperature (38°F-41°F).          │
│   9. Set up assembly station with all ingredients in reach.                 │
│  10. For each container:                                                    │
│      - Layer 1 (bottom): 3 oz brown rice + 2 oz quinoa (mixed)             │
│      - Layer 2: 1 oz baby kale + 0.5 oz arugula                            │
│      - Layer 3: 4 oz herb-roasted chicken (or 3 oz chickpeas)              │
│      - Layer 4: 2.5 oz roasted Brussels sprouts                            │
│      - Layer 5: 1.5 oz diced apples                                        │
│      - Layer 6: 0.75 oz red onion                                          │
│      - Top with: 1 oz goat cheese, 0.8 oz nuts, 0.6 oz cranberries        │
│  11. Seal containers immediately after assembly.                            │
│  12. Package 2 oz dressing separately in portion cup.                       │
│  13. Apply label with product name, assembly date, use-by date (5 days).   │
│  14. Store at 38°F-41°F until delivery.                                     │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

├──────────────────────────────────────────────────────────────────────────────┤
