║  Product: ROASTED VEGETABLES WITH POMEGRANATE                                ║
║  Category: Side Dish - Roasted Vegetables                                    ║
║  Yield: 6 servings                                                           ║
║  Prep Time: 15 minutes                                                       ║
║  Cook Time: 30-35 minutes                                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

┌──────────────────────────────────────────────────────────────────────────────┐
│ INGREDIENTS                                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   ☐ Brussels sprouts, trimmed and halved ................... 1 1/2 lb       │
│   ☐ Butternut squash, peeled and cubed ..................... 1 whole small  │
│   ☐ Red onion, peeled and cut into wedges .................. 1 whole large  │
│   ☐ Olive oil .............................................. for drizzling  │
│   ☐ Salt ................................................... to taste       │
│   ☐ Black pepper ........................................... to taste       │
│   ☐ Chili powder ........................................... 1 tsp          │
│   ☐ Pomegranate sauce / pomegranate molasses ............... 1/3 cup        │
│   ☐ Pomegranate seeds ...................................... for garnish    │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ EQUIPMENT                                                                    │
├──────────────────────────────────────────────────────────────────────────────┤
│   ☐ Large sheet pan (or two)                                                │
│   ☐ Parchment paper (optional)                                              │
│   ☐ Large mixing bowl                                                       │
│   ☐ Cutting board & chef's knife                                            │
│   ☐ Vegetable peeler                                                        │
│   ☐ Measuring spoons & cups                                                 │
│   ☐ Tongs or spatula                                                        │
│   ☐ Serving platter                                                         │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ PREPARATION STEPS                                                            │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   1. Preheat oven to 400°F. Line a large sheet pan with parchment paper.    │
│                                                                              │
│   2. Trim Brussels sprouts and cut in half lengthwise.                      │
│                                                                              │
│   3. Peel butternut squash, remove seeds, and cut into 3/4-inch cubes.      │
│                                                                              │
│   4. Peel red onion and cut into wedges, keeping root end intact so the     │
│      wedges hold together during roasting.                                  │
│                                                                              │
│   5. In a large mixing bowl, combine the Brussels sprouts, butternut        │
│      squash, and red onion wedges.                                          │
│                                                                              │
│   6. Drizzle generously with olive oil. Season with salt, black pepper,     │
│      and 1 tsp chili powder. Toss until evenly coated.                      │
│                                                                              │
│   7. Spread vegetables in a single layer on the sheet pan. Do not crowd —   │
│      use a second pan if needed for proper caramelization.                  │
│                                                                              │
│   8. Roast for 25-30 minutes, tossing halfway through, until vegetables     │
│      are tender and edges are caramelized.                                  │
│                                                                              │
│   9. Remove from oven. Drizzle 1/3 cup pomegranate sauce/molasses over the  │
│      hot vegetables and toss gently to coat.                                │
│                                                                              │
│  10. Return to oven for 3-5 minutes to allow the glaze to set.              │
│                                                                              │
│  11. Transfer to a serving platter and scatter pomegranate seeds over the   │
│      top just before serving.                                               │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ CHEF'S NOTES                                                                 │
├──────────────────────────────────────────────────────────────────────────────┤
│   • For deeper flavor, place Brussels sprouts cut-side down on the pan      │
│   • Cube butternut squash uniformly so it cooks at the same rate as sprouts │
│   • Pomegranate molasses is tart-sweet — taste before adding extra salt     │
│   • Add the pomegranate seeds AFTER roasting to keep them fresh and crisp   │
│   • Serve warm or at room temperature                                       │
└──────────────────────────────────────────────────────────────────────────────┘
