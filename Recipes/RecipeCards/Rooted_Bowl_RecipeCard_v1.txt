┌──────────────────────────────────────────────────────────────────────────────┐
│ PRODUCTION STEPS                                                             │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ PREP (Complete 1 day prior to assembly):                                    │
│   1. Cook quinoa: Rinse, cook in 1:1.5 ratio, fluff, cool completely.      │
│   2. Cook farro: Soak 30 min, cook in 1:3 ratio 30-40 min, cool.           │
│   3. Cook wild rice: Rinse, cook in 1:3 ratio 45-55 min, cool.             │
│   4. Roast sweet potato: Dice ½ inch, toss with oil/salt, roast 400°F      │
│      25-30 min until tender, cool completely.                               │
│   5. Roast portobello mushrooms: Clean, remove stems, slice ¼ inch, toss   │
│      with oil/herbs, roast 375°F 15-20 min, cool.                           │
│   6. Roast chicken: Season with mixed herbs, roast at 375°F to 165°F       │
│      internal, cool, dice into ½-inch cubes, refrigerate.                   │
│   7. Char onions: Slice thick rings, char on grill or cast iron until      │
│      blackened edges, cool, separate rings.                                 │
│   8. Massage kale: Remove stems, tear leaves, massage with olive oil &     │
│      pinch of salt until softened, refrigerate.                             │
│   9. Dice cucumber into ¼-inch pieces, drain excess moisture.              │
│  10. Prepare sauces: Make broccoli pesto & red pepper miso vinaigrette,    │
│      refrigerate in squeeze bottles or portion containers.                  │
│                                                                              │
│ ASSEMBLY (Cold assembly on day of production):                              │
│  11. Verify all components are at proper temperature (38°F-41°F).          │
│  12. Set up assembly station with all ingredients in reach.                 │
│  13. For each container:                                                    │
│      - Layer 1 (bottom): 2.5 oz quinoa + 1.5 oz farro + 1.5 oz wild rice   │
│      - Layer 2: 1.5 oz massaged kale                                       │
│      - Layer 3: 4 oz herb-roasted chicken                                  │
│      - Layer 4: 3 oz roasted sweet potato                                  │
│      - Layer 5: 2.5 oz roasted portobello mushrooms                        │
│      - Layer 6: 1 oz cucumber + 0.75 oz charred onion                     │
│      - Top with: 0.3 oz hemp seeds + 0.5 oz microgreens                   │
│  14. Seal containers immediately after assembly.                            │
│  15. Package sauces separately: 1 oz pesto + 1 oz vinaigrette per unit.   │
│  16. Apply label with product name, assembly date, use-by date (5 days).   │
│  17. Store at 38°F-41°F until delivery.                                     │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ QUALITY CONTROL CHECKPOINTS                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│   ☐ All grains cooled to below 41°F before assembly                         │
│   ☐ Farro cooked until tender but still chewy (not mushy)                   │
│   ☐ Wild rice properly cooked (kernels should "bloom")                      │
│   ☐ Chicken cooked to 165°F internal temp, then cooled properly             │
│   ☐ Sweet potato roasted until tender, not falling apart                    │
│   ☐ Mushrooms roasted until moisture released & browned                     │
│   ☐ Kale properly massaged (darker green, softened texture)                 │
│   ☐ All components layered in correct order for visual appeal               │
│   ☐ Weight check: Final product 15.5-16.5 oz (not including sauces)        │
│   ☐ Microgreens added last to prevent wilting                               │
│   ☐ Labels include: product name, date made, use-by date                    │
│   ☐ Storage temperature maintained at 38°F-41°F                             │

┌──────────────────────────────────────────────────────────────────────────────┐
│ FOOD SAFETY NOTES                                                            │
├──────────────────────────────────────────────────────────────────────────────┤
│   • COLD ASSEMBLY ONLY - Do not assemble with hot components                │
│   • Time in Temperature Danger Zone (41°F-135°F): MAX 2 hours cumulative    │
│   • Wash hands before assembly and after handling each component             │
│   • Use clean gloves throughout assembly process                             │
│   • Sanitize all work surfaces before and after production                   │
│   • Store finished products at 38°F-41°F immediately                         │
│   • Date all components - use FIFO (First In, First Out)                    │
│   • Ancient grains can harbor bacteria if not cooled properly - monitor     │
│   • Mushrooms are high-risk - ensure proper cooking and cooling             │
