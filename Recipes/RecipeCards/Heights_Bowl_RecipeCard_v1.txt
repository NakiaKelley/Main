┌──────────────────────────────────────────────────────────────────────────────┐
│ PRODUCTION STEPS                                                             │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ PREP (Complete 1 day prior to assembly):                                    │
│   1. OPTION A - Sweet Potato Noodles: Peel sweet potatoes, spiralize into  │
│      noodle shapes, blanch in boiling water 2-3 min until just tender,     │
│      shock in ice bath, drain thoroughly, refrigerate.                      │
│      OR OPTION B - Brown Rice: Cook brown rice in 1:2 ratio, cool          │
│      completely on sheet pans in walk-in refrigerator.                      │
│   2. Marinate & grill chicken: Marinate in sesame oil, ginger, garlic,     │
│      soy sauce 2-4 hours. Grill to 165°F internal, rest, slice thin.       │
│      OR Prepare tofu: Press tofu to remove moisture, cube, marinate in     │
│      same mixture, grill or pan-sear until golden, cool.                    │
│   3. Sauté shiitake mushrooms: Clean, remove stems, slice, sauté in        │
│      sesame oil with garlic until golden & tender, cool completely.         │
│   4. Blanch snap peas: Trim ends, blanch in boiling salted water 1-2 min,  │
│      shock in ice bath, drain, pat dry, refrigerate.                        │
│   5. Blanch bok choy: Quarter lengthwise, blanch stems first (2 min) then  │
│      add leaves (1 min), shock in ice bath, drain well, refrigerate.        │
│   6. Shred red cabbage: Slice very thinly using knife or mandoline, soak   │
│      in ice water 30 min to crisp, drain, pat dry.                          │
│   7. Julienne carrots: Peel, cut into matchsticks using mandoline or       │
│      knife, refrigerate in ice water.                                       │
│   8. Quick-pickle vegetables: Slice carrots, daikon, cucumber thinly,      │
│      bring rice vinegar, water, sugar, salt to boil, pour over vegetables,  │
│      cool, refrigerate minimum 2 hours.                                     │
│   9. Make almond lemongrass sauce: Blend almonds, lemongrass, lime juice,  │
│      fish sauce (or soy sauce), garlic, ginger, coconut milk until smooth. │
│  10. Make sunflower seed sauce: Same as above but substitute sunflower     │
│      seeds for almonds (nut-free alternative).                              │
│  11. Wash and pick fresh herbs (mint & cilantro), store in damp towel.     │
│  12. Crush cashews coarsely using knife or food processor.                  │
│                                                                              │
│ ASSEMBLY (Cold assembly on day of production):                              │
│  13. Verify all components are at proper temperature (38°F-41°F).          │
│  14. Drain all vegetables thoroughly (especially sweet potato noodles).     │
│  15. Set up assembly station with all ingredients in reach.                 │
│  16. For each container:                                                    │
│      - Layer 1 (bottom): 5.5 oz sweet potato noodles OR brown rice         │
│      - Layer 2: 1.5 oz shredded red cabbage                                │
│      - Layer 3: 4 oz grilled chicken OR tofu                               │
│      - Layer 4: 2.5 oz sautéed shiitake mushrooms                          │
│      - Layer 5: 1.5 oz blanched snap peas                                  │
│      - Layer 6: 2.5 oz blanched bok choy                                   │
│      - Layer 7: 1 oz julienned carrots                                     │
│      - Layer 8: 1.5 oz pickled vegetables                                  │
│      - Top with: 0.3 oz mint, 0.3 oz cilantro, 0.5 oz cashews, lime wedge │
│  17. Seal containers immediately after assembly.                            │
│  18. Package 2 oz sauce separately (almond lemongrass OR sunflower).       │
│  19. Apply label with product name, assembly date, use-by date (4 days).   │
│  20. Note allergens clearly: TREE NUTS if using almond sauce                │
│  21. Store at 38°F-41°F until delivery.                                     │
│                                                                              │

┌──────────────────────────────────────────────────────────────────────────────┐
│ QUALITY CONTROL CHECKPOINTS                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│   ☐ Sweet potato noodles properly blanched (tender but not mushy)           │
│   ☐ OR Brown rice cooled to below 41°F if using rice base                   │
│   ☐ Chicken cooked to 165°F internal temp, then cooled properly             │
│   ☐ OR Tofu properly pressed before cooking (firm texture)                  │
│   ☐ All blanched vegetables shocked in ice bath (bright color retained)     │
│   ☐ Snap peas still crisp-tender (not overcooked)                           │
│   ☐ Bok choy stems tender, leaves intact (not falling apart)                │
│   ☐ Mushrooms golden brown (not greasy or soggy)                            │
│   ☐ Cabbage and carrots properly drained (no excess water)                  │
│   ☐ Pickled vegetables tangy but not overly acidic                          │
│   ☐ All components layered in correct order for visual appeal               │
│   ☐ Weight check: Final product 15.5-16.5 oz (not including sauce)         │
│   ☐ Fresh herbs added last (vibrant green, not wilted)                      │
│   ☐ Correct sauce packaged (tree nut vs nut-free clearly labeled)           │
│   ☐ Labels include: product name, date made, use-by date, allergens         │
│   ☐ Storage temperature maintained at 38°F-41°F                             │

┌──────────────────────────────────────────────────────────────────────────────┐
│ FOOD SAFETY NOTES                                                            │
├──────────────────────────────────────────────────────────────────────────────┤
│   • COLD ASSEMBLY ONLY - Do not assemble with hot components                │
│   • Time in Temperature Danger Zone (41°F-135°F): MAX 2 hours cumulative    │
│   • Wash hands before assembly and after handling each component             │
│   • Use clean gloves throughout assembly process                             │
│   • Sanitize all work surfaces before and after production                   │
│   • Store finished products at 38°F-41°F immediately                         │
│   • Date all components - use FIFO (First In, First Out)                    │
│   • Sweet potato noodles must be thoroughly drained (high moisture risk)    │
│   • Blanched vegetables are high-risk - cool rapidly after blanching        │
│   • Fresh herbs high-risk for bacterial growth - keep cold & dry            │
│   • Shorter shelf life (4 days) due to high vegetable content & herbs       │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ ALLERGEN INFORMATION                                                         │
├──────────────────────────────────────────────────────────────────────────────┤
│   Contains (if using almond sauce): TREE NUTS (almonds, cashews)            │
│   Contains (if using sunflower sauce): TREE NUTS (cashews only)             │
│   May Contain: SOY (tofu, soy sauce), FISH (fish sauce in almond sauce),    │
│                Gluten (soy sauce unless using tamari)                        │
│                                                                              │
│   Vegetarian: Use tofu protein option                                        │
│   Vegan: Use tofu + ensure sauce uses soy sauce (not fish sauce)           │
│   Nut-Free: Use sunflower seed sauce + omit cashews (use pepitas)          │
│   Gluten-Free: Use tamari instead of soy sauce, verify all components       │
