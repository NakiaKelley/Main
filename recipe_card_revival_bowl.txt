┌──────────────────────────────────────────────────────────────────────────────┐
│ PRODUCTION STEPS                                                             │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ PREP (Complete 1 day prior to assembly):                                    │
│   1. Cook basmati rice: Rinse thoroughly, cook in 1:1.5 ratio (rice:water),│
│      fluff, cool completely on sheet pans in walk-in refrigerator.         │
│   2. Marinate chicken thighs: Combine olive oil, lemon juice, garlic,      │
│      oregano, thyme; marinate thighs 4-24 hours.                            │
│   3. Grill chicken: Cook marinated thighs on grill to 165°F internal,      │
│      rest 5 minutes, slice into strips, cool completely.                    │
│   4. Grill summer squash: Slice lengthwise ¼ inch thick, brush with oil,   │
│      grill 2-3 min per side, cool, cut into bite-size pieces.              │
│   5. Grill portobello mushrooms: Clean, remove stems, brush with oil,      │
│      grill 3-4 min per side, cool, slice into strips.                      │
│   6. Roast bell peppers: Char whole peppers over flame or under broiler,   │
│      steam in covered bowl 10 min, peel, seed, slice into strips.          │
│   7. Roast broccoli: Cut into florets, toss with olive oil & salt, roast   │
│      at 425°F for 20-25 minutes until crispy edges, cool.                  │
│   8. Roast chickpeas: Drain, dry, toss with olive oil & spices, roast at   │
│      400°F for 25-30 min until crispy, cool.                                │
│   9. Prepare tomato-mozzarella salad: Halve cherry tomatoes, dice          │
│      mozzarella, toss with basil, olive oil, salt, refrigerate.            │
│  10. Make tzatziki: Grate cucumber, squeeze out moisture, mix with Greek   │
│      yogurt, garlic, lemon, dill, refrigerate.                             │
│  11. Prepare hummus or use high-quality store-bought, refrigerate.         │
│  12. Portion harissa paste into small containers, refrigerate.              │
│  13. Wash and chop fresh herbs, store in damp paper towel.                  │
│                                                                              │
│ ASSEMBLY (Cold assembly on day of production):                              │
│  14. Verify all components are at proper temperature (38°F-41°F).          │
│  15. Set up assembly station with all ingredients in reach.                 │
│  16. For each container:                                                    │
│      - Layer 1 (bottom): 5.5 oz basmati rice                               │
│      - Layer 2: 4 oz grilled chicken thigh strips                          │
│      - Layer 3: 2.5 oz grilled summer squash                               │
│      - Layer 4: 1.5 oz grilled portobello mushrooms                        │
│      - Layer 5: 2.5 oz roasted bell peppers                                │
│      - Layer 6: 2.5 oz roasted broccoli                                    │
│      - Layer 7: 1.5 oz tomato-mozzarella salad                            │
│      - Layer 8: 1.5 oz roasted chickpeas                                   │
│      - Top with: 0.5 oz fresh herbs mix + lemon wedge                      │
│  17. Seal containers immediately after assembly.                            │
│  18. Package sauces separately: harissa (0.5 oz), tzatziki (1 oz),         │
│      hummus (1 oz) in individual portion cups per unit.                    │
│  19. Apply label with product name, assembly date, use-by date (5 days).   │
│  20. Store at 38°F-41°F until delivery.                                     │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ FOOD SAFETY NOTES                                                            │
├──────────────────────────────────────────────────────────────────────────────┤
│   • COLD ASSEMBLY ONLY - Do not assemble with hot components                │
│   • Time in Temperature Danger Zone (41°F-135°F): MAX 2 hours cumulative    │
│   • Wash hands before assembly and after handling each component             │
│   • Use clean gloves throughout assembly process                             │
│   • Sanitize all work surfaces before and after production                   │
│   • Store finished products at 38°F-41°F immediately                         │
│   • Date all components - use FIFO (First In, First Out)                    │
│   • Fresh mozzarella is high-risk - maintain cold chain                     │
│   • Chicken thighs must reach 165°F during cooking                          │
│   • Tzatziki contains dairy - monitor temperature closely                   │
